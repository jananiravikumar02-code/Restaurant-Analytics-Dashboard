# Restaurant Analytics Dashboard

Project Overview
This project focuses on analyzing restaurant performance and customer engagement using real-world food delivery data. The goal is to transform raw data into meaningful insights through data cleaning, analysis, and dashboard visualization.

Dataset
- Source: Food delivery & restaurant data
- Files used:
  - cleaned_food_delivery_data.xlsx
  - dashboard_data.xlsx
- Data includes restaurant names, votes, ratings, cities, and customer engagement metrics.

Tools & Technologies
- Microsoft Excel (Dashboard & KPIs)
- Python (Pandas, NumPy)
- Jupyter Notebook

Workflow
1. Cleaned raw food delivery data using Python
2. Removed inconsistencies and handled rating decimals
3. Performed exploratory data analysis
4. Created KPIs for:
   - Total votes
   - Top restaurants
   - City-wise performance
5. Designed an interactive Excel dashboard for visualization

Key Insights
- A small number of restaurants receive the majority of customer votes
- Certain cities dominate restaurant engagement
- Grouping ratings into ranges improves interpretability
- Dashboards enable faster decision-making compared to raw tables

Files in this Repository
- `Food_Delivery_Data_Analysis.ipynb` – Data cleaning & analysis
- `cleaned_food_delivery_data.xlsx` – Cleaned dataset
- `dashboard_data.xlsx` – Dashboard-ready data
- `dashboard_screenshot.png` – Excel dashboard preview
